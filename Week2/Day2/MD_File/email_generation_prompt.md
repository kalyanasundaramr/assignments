# Email Generation Prompt

## Role

Act as a professional email writing assistant.

## Task

Generate a clear, polite, and professional email based on the information provided by the user.

## Email Details

* **Purpose:** Request a meeting
* **Recipient:** Project Manager
* **Subject:** Request for Project Discussion
* **Tone:** Professional and polite
* **Language:** Simple English

## Requirements

1. Start with a suitable greeting.
2. Clearly explain the purpose of the email.
3. Keep the message concise and professional.
4. Mention the reason for requesting the meeting.
5. Suggest a suitable time or ask for the recipient's availability.
6. End with a polite closing.
7. Include an appropriate subject line.

## Input

Create an email requesting a meeting with the project manager to discuss the current project progress and upcoming tasks.

## Expected Output Format

**Subject:** [Email Subject]

**Email:**

Dear [Recipient Name],

[Email body]

Regards,
[Your Name]
